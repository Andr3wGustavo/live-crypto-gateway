# README Image Guide

This directory is reserved for real application screenshots. No screenshots have been captured for this gallery yet.

## Planned captures

| Filename | Capture |
|---|---|
| `landing.webp` | Desktop landing page with the main product introduction |
| `dashboard.webp` | Creator dashboard using a dedicated test account |
| `checkout.webp` | Testnet checkout showing network, amount, recipient, and fees |
| `obs-overlay.webp` | OBS preview showing a clearly labeled test alert |
| `mobile.webp` | Mobile landing or checkout, without clipped text |

## Add or replace images

1. Capture the actual application in a supported language. Prefer English for the main repository gallery and record additional locales separately if useful.
2. Use test data. Hide private overlay URLs, OBS tokens, wallet signatures, API credentials, and personal information. Never capture a seed phrase or private key.
3. Export as WebP or PNG. Aim for readable text and under 500 KB per image where practical. Update the README path if using a different extension.
4. Place the file in this directory and move its Markdown image line out of the HTML comment in the root `README.md`.
5. Check the GitHub Markdown preview and add a caption stating whether the image shows preview mode or testnet.
6. Replace the demo-video placeholder with a recording link when the setup journey has been recorded. Do not imply that a test alert proves a real donation.

Keep images current when the interface changes. Do not add an image link before its file exists.
